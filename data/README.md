# データ

- `species_dataset.json`： チャンピオンズの種族データセット（341形態、
  技512件）。出典は Pokémon Showdown の champions mod（技・種族の基礎
  データ）、Serebii のチャンピオンズページ（PP・威力・命中などの実数値）、
  PokeAPI（日本語名）。PPはチャンピオンズの実効値（上限20）に合わせている。
- `type_chart.json`： タイプ相性表（18×18、第6世代以降）。

生成スクリプトは開発環境側にあり、Showdown のローカルチェックアウトを
入力とする。再生成が必要な場合は出典を同じ条件で用意すること。
