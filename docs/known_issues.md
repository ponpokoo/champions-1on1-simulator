# 既知の仕様と評価規約（開示）

## プロジェクト規約：自爆系の両倒れは使用者の負け
てっていこうせん・じばく・だいばくはつ等で両者が同時に倒れた場合、本プロジェクト
では「使用者の負け」として扱う。これは意図的なプロジェクト規約であり、
Pokémon Showdown の解釈（少なくとも てっていこうせん については使用者の勝ちと
読める）とは異なる。結果を読む際はこの差を前提とすること。

## ダメージ計算式の組み替えについて
開発の途中で、ダメージ計算を本編の正規の順序（威力補正→基礎ダメージ→
天候→急所→乱数→タイプ一致→相性→やけど→最終補正）に組み替えた。
- 組み替え前の結果（run1 / run2）は旧計算式の記録として保持されている。
- 組み替えによる検証マトリクスの変化は全14セルで測定され、最大で勝率3.4ptの
  差があった（個別マッチアップではKOラインの反転が起こりうる水準）。

## 観測情報の裁定（v2）
- 「表示はされないが公開情報から計算できるもの」は知っているものとして扱う
  （例：猛毒の段階数は残りダメージの推移から計算できる）。
- 見たダメージの記録（バーの減り幅の最小・最大など）は観測に含めるが、
  ダメージからの正確なステータス逆算は含めない。
- ランダムな残り時間（凍結の解凍など）は経過ターンのみを符号化し、残りは
  符号化しない。
- じゅうりょくで止められた でんじふゆう は技名が公開され、公開上の失敗として
  扱う。呼べる技のない ねごと も公開上の失敗として扱う。

## 適用範囲
- 現在のエンジンと結果はメタグロスの同種ミラー1on1（レギュレーションM-C、
  Lv.50、ポイント合計66・1能力最大32）を対象とする。他種族・他形式への
  一般化は今後の段階である。
- メガシンカは1ターン目からメガ状態として扱う（途中メガは今後の段階）。
