# 段階6a 仕様策定（68技への拡張）— ドラフト

前提： 数値（威力・命中・PP・優先度・接触）は species_dataset.json（Serebii Champions 権威）、
効果は Showdown champions mod（`~/workspace/showdown-champions/data/moves.ts` +
`mods/champions/moves.ts`）を正とする。抽出結果は stage6/move_effects.jsonl。
51技の範囲では Champions mod の技上書きは アイアンヘッド（ひるみ30%→20%）と
すなあらし（PP変更）のみ。ただし68技全体では まもる のPP・シャドークローの
斬撃フラグにも上書きがあり、さらに conditions（状態異常）と scripts（PP上限20・
処理順）に大きな変更がある（Solレビュー）。数値はデータセット側が権威。

## 1. 実装グループ（51技）

### G1 そのまま攻撃（新仕組みなし）
つばめがえし（必中）、シャドーパンチ（必中）、サイコカッター（急所+1）、
ストーンエッジ（急所+1）、バレットパンチ（先制+1）、りんしょう（基本形はここ、連鎖はG5）、
ぶんまわす、サイコショック（特殊だが相手の防御で計算）

### G2 確率・確定の追加効果（既存のひるみ/能力変化の枠で可）
- ひるみ： いわなだれ30%、アイアンヘッド20%（Champions値）、しねんのずつき20%、いびき30%（眠っているときのみ使用可）
- 相手ダウン（クリアボディで無効）： がんせきふうじ（S-1確定）、こごえるかぜ（S-1確定）、
サイコキネシス（D-1 10%）、ラスターカノン（D-1 10%）
- 自分変化： コメットパンチ（A+1 20%）、くさわけ（S+1確定）、アームハンマー（自分のS-1確定。クリアボディ対象外）

### G3 状態異常（新サブシステム、到達可能性はミラー基準）
- 麻痺： かみなりパンチ10%、のしかかり30%。素早さ×0.5、行動不能は **1/8**
  （Champions の conditions 上書き。本編の25%ではない）
- 凍結： れいとうパンチ10%。初期タイマー **3**、行動判定ごとに減算し0で解凍、
  別に **1/4** の早期解凍判定（本編の毎ターン20%ではない）
- 混乱： いばる（命中85、相手を混乱＋相手のA+2。A上昇はクリアボディで防げない）。自傷1/3、2〜5ターン
- 毒： ヘドロばくだんは鋼タイプに無効（ダメージ0・毒も入らない）ため、ミラーでは到達不能。
からげんき（状態異常時に威力2倍）の判定は「眠り以外の状態異常」で、混乱は
対象外（Solレビュー）。眠ったまま ねごと で呼んだ からげんき は威力70のまま

### G4 場・壁・浮遊（新サブシステム）
- リフレクター／ひかりのかべ： 5ターン、物理／特殊ダメージ×0.5（シングル）。
かわらわり・サイコファングはダメージ前に相手の壁を破壊する
- でんじふゆう： 5ターン、地面技無効。じゅうりょく下では無効化される
- じゅうりょく： 5ターン、全技の命中×5/3、両者浮遊無効
- 天気（あまごい／にほんばれ／すなあらし）： 5ターン。ミラーでは実効なし
（水・炎技なし、砂のチップは鋼が無効、岩の特防上昇は対象外）だが状態として実装する
- ステルスロック： 交代のない1on1では無効。設置状態だけ持つ
- こらえる： 優先度+4、そのターンの致死打をHP1で耐える。まもると連続使用カウンタを共有

### G5 特殊な攻撃（個別実装）
- ジャイロボール： 威力 = min(150, 25×相手S÷自分S)（実効素早さ）
- ハードプレス： 威力 = floor(100×相手の現在HP÷最大HP)
- くさむすび： メタグロス同士では体重で威力120固定（通常550kg・メガ942.8kgとも120帯）
- じだんだ： 自分の直前の技が失敗していたら威力2倍
- きあいパンチ： 優先度-3、そのターンにダメージを受けていたら失敗
- メテオビーム： 1ターン溜め（溜め時にC+1）、2ターン目に攻撃
- ギガインパクト／はかいこうせん： 次ターン反動で行動不能
- みらいよち： 2ターン後に遅延攻撃（使用時のCと攻撃時点の相手Dで計算。まもる貫通の有無は6bで Showdown ハンドラを確認）
- じばく／だいばくはつ： 使用後に自分も倒れる。両者同時KO時の勝敗順序は Showdown の扱いに合わせ、6bのフィクスチャで固定する
- すてみタックル： 反動1/3。てっていこうせん： 反動＝最大HPの1/2（Showdown の self ハンドラを6bで確認）
- アイアンローラー： フィールドがないと失敗。フィールドを張る技が68技内にないため、ミラーでは常時失敗（仕様として正しい）
- ワイドフォース： フィールドがない通常条件では威力80の単体技として扱う

## 3. 要承認の設計判断（推奨つき）
- D1 状態異常の範囲：【決定（ユーザー、2026-11-15）：毒・やけどまで全部実装する】
麻痺・凍結・混乱に加え、毒（通常毒＋猛毒の状態）とやけど（物理ダメージ半減を含む
本編仕様）もフル実装する。ミラーでは毒・やけど・猛毒は到達不能だが、段階8
（他種族への一般化）で発生源が現れるため、先行して正しく実装・検証する。
- D2 天気・ステルスロック：【決定（ユーザー、2026-11-15）：推奨どおり】
効果がなくても状態として正しく実装し、将来の種族拡張（段階8）に備える。
【訂正（Solレビュー）： 挙動差はゼロではない。にほんばれ中は新たに凍結しない
ため、こおりパンチのある環境では天気が実際に効く。】
- D3 観測仕様 v2：【決定（ユーザー、2026-11-15）：推奨どおり】
新スキーマ metagross_observation_v2 を切り、技語彙を68に拡張し、
状態異常・壁・天気・浮遊・遅延予約の観測を追加する。g12（v1）は17技専用のまま
凍結し、68技の操縦は 6c のヒューリスティクス拡張 → 6d の学習キャンペーン3で作る。

- D4 回帰規律：【決定（ユーザー、2026-11-15）：推奨どおり】
6b の間、17技の検証マトリクス MD5（21f0b284…）が不変であることを
各グループのマージ条件にする。新システムは未使用時に完全に不活性であること。
68技空間の新しい回帰基準は 6c で策定する。
- D5 数値の権威：【決定（ユーザー、2026-11-15）：修正案】
PP・威力・命中は Serebii Champions を正とする。効果の「事実」（確率・変化量）は
Serebii の Champions 技一覧と Showdown champions mod の両方で突き合わせ、
食い違いがあれば報告して判断を仰ぐ（アイアンヘッドのひるみ20%は両者一致を
確認済み）。処理順序などの「解釈」は mod のハンドラを正とする。

- D6 ダメージ計算式の組み替え：【決定（ユーザー、2026-11-15）】
段階6の中で、calc_damage を本編の正規の処理順に組み替える。現行は近似
（補正を各段で切り捨て、乱数が最後、ランク補正後の能力値が浮動小数、
かたいツメが威力×1.3切り捨て、アイテム補正が四捨五入寄り）。組み替え内容：
(1) 順序を 基礎値 → 天気 → 急所 → 乱数 → タイプ一致 → 相性 → やけど →
その他補正（壁・アイテム・特性等は4096分率で合成し最後に1回だけ丸める、
0.5は切り捨て）に統一する。(2) ランク補正後の能力値は整数化してから使う。
(3) かたいツメは ×5324/4096 の補正として扱う。(4) 推定用の est_damage も
同じ順序に揃える。D4 への例外： 組み替えの時点で一度だけ、差分レポート
（マトリクスの変化セル数と変化幅）つきで回帰基準を作り直し、以降は新しい
MD5 を不変条件とする。run2 の結果は近似式のままで確定するが、式の差が
勝率に与える影響は「誤差範囲」と決めつけず、移行レポートで実測する
（Solレビュー指摘： 確定数・PP・ターン数のフィードバックで増幅されうる）。
68技の学習と run3 は新式で行う。また補正はフックごとに段階が決まっており
（威力段： かたいツメ **5325/4096**・ハチマキ・タイプ強化 ／ ダメージ段：
壁・いのちのたま）、全部を最終段に潰さず段階と丸め位置を保持する。

## 5. Solレビューによる修正・追加（2026-11-15、stage6/sol_review_6a.md）
以下はドラフト本文より優先する。
- みらいよち： まもる を貫通する（みがわりは貫通しない）。攻撃側の数値は
  予約時ではなく「着弾時点の現在値」を使う。Tターン予約 → T+2 のターン終了時
  に着弾。同じ場所への二重予約は失敗。いのちのたまの判定も着弾時。
- りんしょう（Round）： 1on1でも常に60ではない。両者が選ぶと後の行動が連鎖して威力120。
  りんしょう（Round）と いびき は音技で みがわり を貫通する（抽出でフラグを取りこぼし）。
- てっていこうせん： mindBlownRecoil。外れ・まもる でも「試行」すれば最大HPの
  半分（切り上げ、例：155→78）を失う。着弾・失敗経路で二重に数えない。
- じばく・だいばくはつ： 使用者は外れ・まもる でも倒れる。両者同時に倒れたら
  使用者側の負け（現行エンジンの「両方0以下＝引き分け」を自爆系だけ分離する）。
- 同時ひんしの勝敗は「倒れる順序」で決まる仕組みとして実装する
  （ユーザー確認、2026-11-15）： 自爆系と てっていこうせん（コスト・反動で
  使用者が倒れる）→ 使用者の負け。一方、クロロブラスト（68技には含まれない、
  段階8の範囲）は反動がダメージの後に処理されるため、両者同時に倒れても
  使用者の勝ちになる仕様がある。勝敗判定を一律にせず、仕組みごとの順序で持つ。
- かわらわり・サイコファング： 壁の破壊は onTryHit（みがわり・ダメージより前、
  ただし まもる・命中判定より後）。急所は壁を無視するが壊さない。
- きあいパンチ： 集中が解けるのは「本体への直接の攻撃技ヒット」のみ
  （みがわりで受けたら解けない）。解けた場合はPPを消費しない。準備の宣言は
  両者の選択が確定した後にのみ観測される。
- じだんだ： 判定は前ターンの moveLastTurnResult（失敗したかどうか）の意味論。
  まもる で防がれた場合は対象外（NOT_FAIL）。成功/失敗/強制スキップ/未試行を
  区別する状態を毎ターン保持する。
- 変動威力の正確な式： ジャイロボール = min(150, ⌊25×相手S/自分S⌋+1)
  （同速で26）。ハードプレスは固定小数点式（93/155→59、下限1）。
  すてみタックルの反動は 33/100 を「実際に与えたダメージ（みがわり込み、
  残HP上限）」に掛ける（77ダメ→25）。くさむすびは接触の特殊技。
- じゅうりょく： 命中補正は正確に 6840/4096。発動時に でんじふゆう を即消去し、
  ふうせんは消費せず地面に落とす（終了後に浮遊が戻る場合がある）。
  てつのたま所持は でんじふゆう 中でも接地する。
- 睡眠の初期ターンは重み [2,3,3]（Champions conditions）。ただし ねむる は
  自前のタイマー3で、現行エンジンの ねむる モデルは置き換えない。
- PP： Champions は基礎PPの上限20（データセットの実効PPが権威。抽出JSONLの
  生PPは使わない。例： バレットパンチ 生30 → 実効20）。
- D5 の記録事項： からげんき の対象について Serebii の文面は凍結を挙げないが
  ハンドラは「眠り以外の状態異常」→ ハンドラを採用。すてみタックルは
  Serebii の「1/3」ではなくハンドラの 33/100 を採用。

### 6b に入る前の表現層の前提作業（Sol指摘）
- PublicMon.lock_set は int のビット集合で技IDが大きいと溢れる。v2 は
  69仮説（なし＋68技）を 2×uint64 で持つ。v1 の表現は凍結。
- MV_COUNT が わるあがき の番兵を兼ねている（17）。技追加で衝突するため、
  内部の行動種別と版ごとのワイヤIDを分離する。
- g12/MGO1 は凍結し、新語彙の対戦は黙って切り詰めず拒否する。
- 回帰受け入れは MD5 だけでなく、旧技だけの対戦で「結果・ターン数・最終RNG
  状態」まで一致させること（観測ON/OFF両方）。verify.py は段階6用に
  監査方式を作り直す（旧ファイルのバイト比較はそのまま使えない）。
