# 同梱サンプル探索結果 (`viewer/examples/`)

このディレクトリには、ローカルサーバや大規模計算を実行せずにワークベンチの結果分析タブを体験できる**実測サンプルデータ**を収録しています。

## `sylveon-standard`（既定サンプル）

- **種族**: `sylveon`（ニンフィア）
- **探索規模**: `standard`（標準：候補 200,000 → 決勝 112 型、各ペア 240 戦）
- **候補生成**: `sampled`（`filters` 指定あり：`sylveon-standard/finals_results.json` 内の `filters` 参照）
- **操縦方針**: `obsh4`（公開情報のみを使う標準ヒューリスティクス・観測 v3）
- **類型・局所最適化パス**:
  - 4 技を保持したまま実戦技使用率を計測（60 戦/組）し、無駄振り再配分・性格合理化の局所候補を 3 条件安全ゲート（60 戦/組/席）で検証
  - 採用 72 型 / ゲート保留 1 型 / 元型クリーン 39 型の最適化後 112 型プールで総当たり（60 戦/組）を再計算
- **シード**:
  - 候補サンプリング: `20263010` / パネル: `20263011`
  - Stage A: `20263310`〜 / Stage B: `20263350` / 決勝: `20263360`（＋シャード番号）
  - 最適化・使用率計測: `20265000`
- **ファイル**:
  - `sylveon-standard/finals_results.json`: 生の決勝総当たり結果の原本 JSON
  - `sylveon-standard/finals_polished.json`: 技使用率・類型一覧・局所最適化後プールの JSON
  - `sylveon-standard/sample_meta.json`: 上記条件のメタデータ

## `gyarados-light`

- **種族**: `gyarados`（ギャラドス、メガギャラドス含む）
- **探索規模**: `light`（軽量：候補 60,000 → 決勝 64 型、各ペア 160 戦）
- **候補生成**: `sampled`（`filters` 指定あり：`gyarados-light/finals_results.json` 内の `filters` 参照）
- **操縦方針**: `obsh4`（公開情報のみを使う標準ヒューリスティクス・観測 v3）
- **シード**:
  - 候補サンプリング: `20263010` / パネル: `20263011`
  - Stage A: `20263310`〜 / Stage B: `20263350` / 決勝: `20263360`（＋シャード番号）
  - 簡易 24 型（参考）計測: `20264001`（24 型 × 両視点各 50 戦）
- **生成時点コミット**: `121ef69344fe15f1a8a947f9d39c19251a978e9d`
- **ファイル**:
  - `gyarados-light/finals_results.json`: 決勝総当たり結果の原本 JSON
  - `gyarados-light/beginner_scores.json`: 簡易 24 型（参考）に対する計測結果の原本 JSON
  - `gyarados-light/sample_meta.json`: 上記条件のメタデータ
  - `sample_data.js`: `file://` 直開きでもワンクリックで分析できるよう上記実データをそのまま埋め込んだ JS ラッパー

> **注記**: 本データは個人の `runs/` 配下の探索結果とは完全に独立しています。勝率・順位は上記の候補条件・決勝プール・操縦方針（`obsh4`）に基づく実測値であり、全組み合わせに対する普遍的な最強型を示すものではありません。
